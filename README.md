# yiju-zhao.github.io

Personal portfolio, generated as a static page for GitHub Pages. No dependencies or client-side JavaScript.

```sh
node build.mjs
```

Edit project data and copy in `build.mjs`, then regenerate `index.html`. `styles.css`, `base.css`, and `tokens.css` control the layout and appearance.

The page has three selected works, three experiments, a public repository index, and expandable project records. Architecture diagrams use the existing renderer and validate labels and connector routing during the build.

See [portfolio references](research/portfolio-references.md) for the first-party examples and editorial decisions behind this version.
