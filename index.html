Agent tools · Validating · Agent workflow

herdr-pm

A project board for Claude Code and Codex sessions running across multiple machines.

Track progress, decisions and open questions by project, with a path back to the original conversations.

Each machine reads its local sessions and pushes updates to a central SQLite service. The service exposes a web interface and MCP tools. Collectors advance their cursors after acknowledgement so interrupted transfers can resume.

  • TypeScript
  • SQLite
  • MCP

Noteweaver

A knowledge bank in Obsidian where claims keep their sources and agents follow the same rules as daily editing.

A shared TypeScript kernel validates pages, claims, evidence and relations, inside Obsidian and in offline CI.

The Obsidian plugin handles daily editing. The Agent plugin provides skills for queries, writing and research. Each vault defines its own schema and policies. Structure checks and factual verification are separate operations.

  • Obsidian
  • TypeScript
  • Agent skills

Investment research · Validating · RSI / strategy research

rsi-quant

An agentic research loop for quantitative strategies. An LLM proposes changes; a deterministic engine runs walk-forward evaluation, trading costs and a lockbox holdout.

RSI means recursive self-improvement here. Strategies can iterate automatically; changes to prompts, skills and workflows remain human-merged proposals with evidence and rollback. This is research with paper portfolios.
