看我在造什么 关于我

想到就造出来

我喜欢把想法直接做成能用的东西:agent 的工具链、给家里人用的产品、管住自己手的投资系统。

很多项目的第一个用户是我自己。

先做给自己用
看板和家庭数据是我自己要用的,中文课是给家里人的。
不信模型自觉
用代码校验、实测门和对照评委,代替"它应该会做对"。
也不信自己
投资分析下结论前冷却 48 小时,还要补一条反面证据,否则系统拒绝执行。
能只读就只读
连接器只读,不接非官方 API,中心不登录任何机器。

正在造的四个

每个都写了为什么造、我做了什么取舍、现在到哪了。

  1. agent-pm

    把多台机器上的 agent session 汇总到一个中心,按项目看进度。

    为什么造
    同时开着十几个 agent,分在四台机器上,我记不住谁在做哪件事。
    我的判断
    中心不 ssh 任何机器。采集器只推不拉,游标等中心确认才前进,断网重启不丢不重。
    现在
    在四台机器上跑着,这个页面的项目清单就来自它。
    仓库
    GitHub 仓库

  2. openlingo

    以识字为主线的 AI 中文启蒙,故事只用孩子学过的字。

    为什么造
    想替掉现在上的中文网课:识字为主线,30 分钟一节。
    我的判断
    6 岁前不教拼音。故事只许用学过的字,由代码逐字校验,不靠模型自觉。绘本做有声翻页,不做 AI 重绘动画。
    现在
    验证版搭好了,还差一次真实绘本的端到端跑通。
    仓库
    未公开

  3. cangjie-skill

    把书、长视频、播客蒸馏成 Agent Skill,再用装与不装的对照实测。

    为什么造
    一本好书能不能变成 agent 真的会用的 skill?
    我的判断
    蒸馏出来不算数,装与不装对照实测才算。评委先抹掉作者和书名线索,再双向各判一次。
    现在
    fork 里加了 measure.py 实测门,拿纳瓦尔和两本读财报的书试过。
    仓库
    GitHub 仓库

  4. rsi-quant

    ETF 轮动与杠杆择时,每日研究,过 lockbox 才进模拟盘。

    为什么造
    想知道 ETF 轮动加杠杆择时,能不能稳定跑赢 SPY。
    我的判断
    回测好看不算数,候选策略过了 lockbox 才算正式盘。
    现在
    每天凌晨自动研究,几本模拟盘在跑。
    仓库
    未公开
