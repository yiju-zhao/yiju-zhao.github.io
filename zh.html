作品

从实际工作中长出来的工具。

  1. Agent workflow个人使用中

    herdr-pm

    源码 ↗

    为多台机器上的 Claude Code 和 Codex 会话做的项目看板。

    按项目查看进度、决策和待处理的问题，也能追溯到原始会话。

    • TypeScript
    • SQLite
    • MCP
    实现细节

    每台机器的采集器只读本地会话，再推送到中心。中心用 SQLite 保存记录，同时提供网页和 MCP 接口。采集游标在收到确认后才前进，断线后可以续传。

  2. Personal knowledge开源

    Noteweaver

    源码 ↗

    让 agent 帮忙整理知识，也让每条结论保留可以回头查的出处。

    在原生 Obsidian 里管理知识页、断言和证据。同一套规则供日常编辑与离线校验使用。

    • Obsidian
    • TypeScript
    • Agent skills
    实现细节

    共享的 TypeScript 内核负责校验与变更计划，Obsidian 插件负责日常编辑，Agent 插件提供查询、写入、研究等技能。每个知识库自己定义 schema 和政策。结构校验与事实核查分别处理。

  3. Cross-device tooling开源

    Herdeo

    源码 ↗

    电脑前用原生终端，离开电脑后，手机也能接着处理同一个 agent 会话。

    连接 Herdr 和 Paseo，同步消息、工具结果与支持的授权请求，保留原生 CLI 的交互。

    • Node.js
    • Herdr
    • Paseo
    实现细节

    Codex、Claude Code 和 Pi 使用各自的接入方式。桥接连接终端里已有的原生进程；手机和电脑操作的是同一个会话。当前远程输入支持纯文本，高级 CLI 操作仍在终端进行。

  • rsi-quant

    RSI / 策略研究

    量化策略的 agentic research loop：LLM 提出改动，确定性引擎执行 walk-forward 评估、交易成本核算与 lockbox 留出验证。

    实现细节

    这里的 RSI 指递归自我改进。策略可自动迭代；prompt、skill 与工作流的修改保留为人工合并的提案，附证据与回退路径。目前仍是研究与模拟盘。
